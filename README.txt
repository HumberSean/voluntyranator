HOW TO USE THE VOLUNTYRANNATOR

1. Open the studentlist.js file with Notepad (Windows) or TextEdit(Mac) - or any text editor if you work with code.
2. Click on the Voluntyrannator_stuff folder.
3. Click on classfilemaker.html so that it opens in a browser.
4. Follow the instructions on the page to modify your student list from a .csv file.
5. Copy and paste the results from classfilemaker.html into the studentlist.js file, then save the file.
6. Now, click on volunteer.html (top level of the folder) to access the Voluntyrannator!
