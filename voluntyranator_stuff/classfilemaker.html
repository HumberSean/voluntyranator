Voluntyrannator Class File Builder

  1. Download your class file from myhumber.
  2. Select all of the student names from the names column, then copy and paste them into the space below.
  3. Get rid of middle names if you wish, or modify first names as requested by students — be sure not to delete any commas.
  4. Click 'Create JavaScript File'.
  5. Copy the generated text and paste it into the studentlist.js file, then save the file.
  6. Your Voluntyrannator should be good to go!
  7. Click on volunteer.html to fire up the Voluntyrannator!
